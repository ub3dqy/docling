## Что исправлено

- В широких низких таблицах учитываются наклон и настоящие границы сетки. Восстановлены последние строки, годовые столбцы и напечатанные прочерки. Повторно обнаруженная цифра удаляется только при совпадении исходных участков.
- Повреждённые суммы перечитываются из собственного полного участка изображения. Итог чека хозтоваров восстановлен с `11(760.00` до `1760.00`, сумма продуктового чека — с `6686` до `99.99`. Более слабое чтение не перезаписывает подтверждённое число.
- Разделяются надписи соседних чеков и банковского слипа. При сильном наклоне подпись и сумма сохраняют свои исходные положения. НДС `6.67` не теряется из-за объединения с далёкой подписью.
- Восстановлены заголовок «Кассовый чек», название клиники с кавычками и фразы благодарности. Ставка `10%` подтверждается чтениями источника; повреждённый процент не становится новой цифрой ставки.
- В аудиторском мнении исправлены `рода` / `года`, закрывающая кавычка и тире. Для замены требуется согласие двух моделей по полной строке; числа и их положения сохраняются.
- В чеке хозтоваров восстановлен `=` перед суммой без НДС. Проверяются два напечатанных штриха и согласованные чтения моделей. Неравномерная толщина штрихов допустима только при дополнительном подтверждении. Минус, двоеточие и число не подменяются.

Все четыре чека прошли проверки выбранных цен, итогов, скидки, оплаты и НДС. Их контрольные текстовые отрывки совпали полностью. Двоеточие в двух суммах клиники остаётся неоднозначным знаком опубликованного чёрно-белого снимка. Числовой проверяющий допускает эквивалентное целое значение; это не доказывает точное чтение десятичного разделителя. В контрольных текстовых отрывках эти суммы не оцениваются посимвольно. Особенность подробно описана в первом отчёте.

Проверка до и после прогона подтвердила сохранность программы, 36 файлов моделей, 21 прежнего контрольного JSON, исходных документов, зависимостей и обеих программ измерения. Служебная папка `.cache` с метаданными загрузчика исключена из списка моделей.

Параметры: профиль `ru`, CPU, 4 потока, 180 секунд на страницу. Модели находятся в локальной папке. Во время распознавания блокируются Python-соединения; общий перехват сетевого трафика не проводился. Зависимости и модели в этой доработке не обновлялись.

Повтор комплекта B в новую пустую папку:

```powershell
$env:PYTHONUTF8 = '1'
uv run --no-sync python -c 'from pathlib import Path; import scripts.qualify_real_russian_ocr as q; q.FIXTURES=Path("tests/data/russian_ocr_holdout_20261102b"); q.main()' --sources output/russian-ocr-holdout-2026-11-02b/sources --artifacts-path model_artifacts/ru --output output/repeat-improved-b --use-source-review
```

Без `--use-source-review` сохраняется сравнение с исходным ошибочным ответом НДС. Дополнительная сверка текста приведена в `supplementary_source_text_review` нового отчёта и не меняет результат этой команды.

Проверки обработки: **580 пройдены, 7 пропущены**; проверки русского профиля и запуска: **12 пройдены**. Пропуски: EasyOCR, отдельная программа Tesseract и пять проверок только для macOS. Русский профиль использует установленную библиотеку Tesseract и проверяется настоящим распознаванием. Доступный на Windows эквивалент `make validate`, команда `prek`, пройден. Код проверен повторно; исключённые из автоматического выбора тесты, изображения и документация проверены отдельно.

Результат относится к перечисленным контрольным участкам. Он не подтверждает точность всего текста документов, рукописи, печатей, QR-кодов или любых новых фотографий.
