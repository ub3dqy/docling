# Новый комплект E

Десять страниц из восьми новых публичных оригиналов: шесть фотографий чеков,
три страницы финансовой отчётности и первая страница аудиторского заключения.
Файлы не совпадают с 199 прежними оригиналами и кандидатами по контрольной
сумме. Дополнительно проверено сходство фотографий; ближайшие различия составили
14–22 из 63 признаков. Это проверка новизны относительно местных файлов.

Шесть чеков выбраны по заранее заданному правилу из ещё не использованных
изображений закреплённой версии
[receipt-ocr-ru](https://huggingface.co/datasets/cdek-ocr/receipt-ocr-ru/tree/50a7383534b3fe498c49eff9e7bb35b20f300eba/images/test):
первые шесть по хешу строки `ru-primary-2026-11-03e` и хеша файла.
Выбор сделан до просмотра изображений; все шесть оставлены. Разметка издателя
и результаты его распознавания не загружались. Из-за ошибок загрузки четыре
фотографии повторно получены через системное хранилище доверенных сертификатов
Windows; проверка сертификатов не отключалась. Байты сверены с хешами издателя.

Отчётность и заключение опубликованы
[Гарантийным фондом Владимирской области](https://garantfond-33.ru/dokumenty/otchyetnost/otchetnost-2025-god/).
Проверяются страницы 2, 3, 4 отчётности и страница 1 заключения. На каждой
нет готового текста и есть одно растровое изображение. Это сканы, а не проверка
готового текстового слоя.

Ответы прочитаны по изображениям до первого распознавания E. Проверяются
135 значений таблиц, 58 числовых полей и 14 текстовых областей. Числа не
вычислялись. Неразборчивые сведения вне выбранных областей, реквизиты, подписи,
штрихкоды и QR не оцениваются. Отдельные подстроки таблиц без уникальных кодов
также не входят в числовой контроль. Прочерки внутри типографских скобок
записаны как прочерки; числовые убытки в скобках — как отрицательные числа.

Фотографии издатель уже перевёл в чёрно-белый вид. Повернутый чек подаётся
в исходном виде; его области проверки перенесены в координаты оригинала.
Иллюстрации с рамками служат только для ручной проверки ответов и не передаются
программе. Исходники остаются в `output/russian-ocr-holdout-2026-11-03e/sources`;
права на документы сохраняются у авторов.

До первого запуска сохраняются:

- `references.json`, `sources.json`: ответы, области и хеши оригиналов.
- `collection-plan.json`, `novelty.json`, `scan-evidence.json`: выбор и проверка источников.
- `evaluation-seal.json`: первая фиксация ответов и программы до распознавания E.
- `run-seal.json`: окончательная программа после проверок на прежних документах.

Между этими фиксациями программа может меняться только по прежним документам;
ответы E остаются неизменными. Первый результат E сохраняется вместе с ошибками.
Нейросети не дообучаются. Неизвестно, были ли похожие публичные материалы в их
первоначальном обучении. Формы чеков повторяются, а три финансовые страницы
относятся к одному оригиналу. Такой небольшой комплект не доказывает точность
на любых документах.

Для повторения, из корня проекта с локальными моделями, укажите новую папку:

```powershell
uv run --no-sync python -c 'from pathlib import Path; import scripts.qualify_real_russian_ocr as q; q.FIXTURES=Path("tests/data/russian_ocr_holdout_20261103e").resolve(); q.main()' --sources output/russian-ocr-holdout-2026-11-03e/sources --artifacts-path model_artifacts/ru --output output/holdout-e-repeat
```

Проверяющая программа и правила сравнения сохранены: CPU, четыре потока,
180 секунд на документ, сетевые соединения Python при распознавании запрещены.
Прохождение случая требует всех его условий и не равно доле правильных букв.

Первый прогон и последующее сравнение с исходной программой сохранены в

записано `1 115 238`, а на источнике стоит `1 115 283`. Есть и ограничение
сравнения полного прочерка в скобках `( - )` с ответом `-`.
Первоначальные ответы, их контрольная сумма и обе исходные оценки оставлены
без изменений; эти замечания не использовались для настройки программы.
