# Независимый комплект D

Десять страниц из девяти новых публичных оригиналов: шесть фотографий чеков,
две страницы бухгалтерского баланса, одна страница финансовых результатов
и первая страница аудиторского заключения. Документы собраны 2 ноября 2026 года
по UTC; проверка проходит после исправления выбора чтений и сборки документа.

Правильные ответы, области проверки и исходные файлы зафиксированы
в `evaluation-seal.json` до первого распознавания этого комплекта. Этот файл
содержит и первый снимок программы. Последующие исправления проверяются только
на прежних документах; окончательный снимок для первого прогона D сохраняется
отдельно в `run-seal.json`. Правильные ответы D остаются неизменными.
Контроль содержит 95 значений таблиц, 48 числовых полей чеков и участки текста.
Числа сверены с печатью на изображении. Расчёты для получения ответов не применялись.

Шесть чеков выбраны равномерно из ещё не использованных файлов закреплённой версии
[receipt-ocr-ru](https://huggingface.co/datasets/cdek-ocr/receipt-ocr-ru/tree/50a7383534b3fe498c49eff9e7bb35b20f300eba/images/test)
до просмотра результатов распознавания. Контрольные суммы совпадают с данными
издателя. Фотографии уже переведены издателем в чёрно-белый вид; цветных оригиналов
нет. Три чека используют сходный бланк одной столовой. Чек `IMG_1437` подаётся
в исходном повёрнутом виде. Его плохо различимая сумма НДС заранее исключена;
остальные читаемые поля оставлены.

PDF опубликованы [Гарантийным фондом Волгоградской области](https://nprgf.com/docs/).
Баланс и финансовые результаты не имеют готового текста. В аудиторском PDF
доступна только одна цифра номера страницы; основной текст находится в изображении.

Сохранены:

- `references.json`: ответы и области, записанные по изображениям до распознавания.
- `sources.json`: адреса, размеры и контрольные суммы девяти оригиналов.
- `novelty.json`: отсутствие повторов среди 190 прежних файлов и проверка сходства.
- `scan-evidence.json`: проверка готового текста и изображений PDF.
- `collection-plan.json`: выбор исходников до распознавания.
- `evaluation-seal.json`: исходное состояние программы, моделей и входных данных.
- `run-seal.json`: окончательное состояние программы перед первым прогоном D.

Это новая группа относительно местных проверок. Неизвестно, встречались ли
подобные публичные материалы при первоначальном обучении нейросетей.
Проверяются выбранные участки, а не каждый знак девяти документов.
Исходные фотографии и PDF остаются в местной папке
`output/russian-ocr-holdout-2026-11-02d/sources`; права на них сохраняются у авторов.
Нейросети в этой работе не обучались.

Результаты первого запуска и оставшиеся ошибки сохраняются в
[отчёте об исправлениях](../russian_ocr_system_fixes_20261103/REPORT.md)
и [исходных оценках D](../russian_ocr_system_fixes_20261103/d-first.json).

Для повторения с этими оригиналами и локальными моделями, из корня проекта:

```powershell
uv run --no-sync python -c 'from pathlib import Path; import scripts.qualify_real_russian_ocr as q; q.FIXTURES=Path("tests/data/russian_ocr_holdout_20261102d").resolve(); q.main()' --sources output/russian-ocr-holdout-2026-11-02d/sources --artifacts-path model_artifacts/ru --output output/holdout-d-repeat
```

Папка результата должна быть новой. Проверяющая программа работает без сетевых
соединений Python, на CPU с четырьмя потоками и прежним ограничением 180 секунд
на документ. При несовпадении ответа она сохраняет ошибку и продолжает остальные
случаи; условия проверки не ослабляются.
