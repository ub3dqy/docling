# Новая группа F: реальные русскоязычные документы

Шесть ранее не использованных фотографий чеков и четыре страницы двух сканов PDF. Ответы, области и состав проверки записаны до первого распознавания группы F. Все шесть первоначально выбранных фотографий сохранены. Первое измерение после исправлений сохраняется отдельно от сравнения с исходной версией.

- 10 страниц, 8 оригиналов. 91 выбранное значение таблиц, 70 числовых полей и 12 текстовых областей.
- Отчётность: страницы 1, 3 и 4; аудиторское заключение: страница 2. Страница 4 отчётности — целевое использование средств. У всех четырёх страниц нет готового текстового слоя.
- Фотографии: цены и количество, итоги, оплата, НДС 5%, 10% и 20%; один напечатанный отрицательный размер скидки. Исходники уже переведены издателем в чёрно-белый вид. Три фотографии существенно повёрнуты.
- Четыре цены магазина рукоделия имеют неоднозначные дробные цифры и исключены до распознавания. Их количество, итог, оплата и НДС проверяются. Ожидаемые суммы не вычисляются из соседних значений.
- Правила выбора, адреса, размеры и SHA256 — в `collection-plan.json` и `sources.json`. Шесть фотографий выбраны по минимальным хешам с фиксированной строкой выбора из неиспользованных изображений закреплённой версии открытого набора [receipt-ocr-ru](https://huggingface.co/datasets/cdek-ocr/receipt-ocr-ru). Лицензия набора — MIT. Разметка издателя не загружалась. PDF взяты с сайтов организаций.
- Все восемь SHA256 отсутствуют среди 207 прежних файлов. Ближайшие расстояния изображений — 14, 22, 20, 20, 20 и 18 из 63; это дополнительная проверка изображения, а не доказательство независимости содержания. Общие формы чеков и три страницы одного отчёта связаны между собой. Неизвестность для моделей при обучении не установлена.

Изначальная разметка уточнена по исходным изображениям до любого распознавания F: область одного заголовка сужена до читаемых слов, области другого чека проверены в полном разрешении. Числа и состав документов не менялись. Исходный и окончательный хеши сохранены в `annotation-review.json`.

Области повёрнутых чеков перенесены в координаты исходных фотографий. Программа получает исходные файлы без этих поворотов и обрезок. Прямоугольник на наклонной фотографии может захватить соседнюю печать. Числовая проверка требует наличия значения в заданной области и экспорте; она не доказывает правильную связь каждой подписи с суммой. Повторяющиеся подписи строк оцениваются прежним правилом выбора наиболее совпадающей строки. Проверка охватывает только заранее выбранные части документа.

При сборе также загружен 77-страничный PDF с текстовым слоем. Он исключён до распознавания, потому что не является сканом. Запись сохранена в плане. Плохое распознавание не является основанием для исключения файла.

Исходные файлы хранятся локально в `output/russian-ocr-holdout-2026-11-03f/sources`; повторно в Git не включены. Для повторной проверки скачайте точные файлы из `sources.json` и проверьте их SHA256. Настройки: русский профиль, процессор, 4 потока, 180 секунд на документ. Исходный оценщик `scripts/qualify_real_russian_ocr.py`, нормализация и пределы ошибок сохранены. Эталонные ответы, модели и зависимости при сравнении неизменны.

Общий отчёт сравнения: [исправления чеков и повторная проверка](../russian_ocr_receipts_20261103/REPORT.md).
