исправления `96762259c04921ae8f9493c496ab08e0594ce25b`. Их контрольные суммы
не совпадают ни с одним файлом прежней выборки `russian_ocr_real`.

Код распознавания, модели и русская настройка при проверке не менялись.

документах. Коллекции фотографий и чеков использовались раньше, но сами файлы —
новые для этой проверки. Неизвестно, входили ли они в обучение сторонних моделей.

## Повторение проверки

Используется прежняя программа проверки с явно выбранной папкой новых образцов:

```powershell
uv run --no-sync python -u -c 'from pathlib import Path; import scripts.qualify_real_russian_ocr as q; q.FIXTURES = Path("tests/data/russian_ocr_unseen").resolve(); q.main()' --sources output/real-russian-ocr-new-2026-11-01/sources --artifacts-path model_artifacts/ru --output output/real-russian-ocr-new-repeat/results
```

Папка результата должна быть новой или пустой. Команда сначала проверяет
контрольные суммы, сохраняет использованные образцы, код и настройки, затем
обрабатывает документы локально. Без `--use-source-review` используются
первоначальные ответы. Именно так получен первый результат ниже.

Для улучшенной версии добавьте `--use-source-review`. Он применяет только
документированные поправки из `reference_adjudications.json` и сохраняет
оценки по обоим вариантам. Исходные ответы, страницы, области и пределы ошибок
остаются неизменными. Эта выборка теперь используется при разработке;
повторная проверка не является испытанием на незнакомых документах.

Успех преобразования и правильность распознавания учитываются отдельно.
Каждое число таблицы должно оказаться в своей строке. Поле чека должно быть
верно в своей области и присутствовать в обычной текстовой выгрузке. Для пяти
участков текста считаются пропуски, замены и лишние символы. Регистр и повторные
пробелы не учитываются; различия букв, цифр и знаков учитываются.
Предел ошибок — 5% для печатного абзаца и обложки, 10% для шумных чеков.
Для оценок требуется точно прочитанное название предмета: сама цифра `5`
не означает правильного соответствия строки.

Оценка относится только к перечисленным страницам и участкам. Подписи, печати,
рукопись, закрытые сведения, QR-коды, штрихкоды и повреждённая мелкая печать
вне этих участков не проверяются. Повреждённые знаки перед НДС первого чека
не входят в оценку знаков; цифры его НДС проверяются отдельно. Полный список
исключений сохранён в `references.json` до запуска.

исходного баланса найдены четыре перестановки цифр в первоначальных ответах.

значений между строками.

в `reference_adjudications.json`. Баланс проверялся при 288 точках на дюйм

`references.json` сохранён без изменения байтов. В первом прогоне обе строки
имели ноль совпадений, поэтому эти уточнения не меняют его результат `4/10`.
